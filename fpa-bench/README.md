# fpa-bench

A benchmark for testing LLMs and agent harnesses on **FP&A / strategic finance** work:
variance analysis (price/volume/mix, FX/organic), three-statement modeling, 13-week cash
forecasting, driver-based forecasting with revenue recognition, SaaS metrics, cohort retention,
capital allocation, unit economics, model error detection, and board-level narrative.

All data is **synthetic and seeded** — inputs and answer keys are generated by code
(`bench/generators.py`), so the benchmark is contamination-resistant and infinitely refreshable.
11 of 12 tasks are graded deterministically (JSON answers, per-field numeric tolerance, partial
credit); the board-memo task uses a rubric-based LLM judge. See `DESIGN.md` for rationale and
`docs/RESEARCH.md` for the July 2026 benchmark-landscape survey this design responds to.

## Quick start

```bash
cd fpa-bench
pip install -r requirements.txt        # just pytest; runner is stdlib-only

python -m bench list                   # show the 12 tasks
python -m bench validate               # independently re-verify every answer key
python -m bench show --task variance-pvm-001 --mode chat   # inspect a rendered prompt

# Run against models (set ANTHROPIC_API_KEY / OPENAI_API_KEY / OPENROUTER_API_KEY):
python -m bench run --model anthropic/claude-sonnet-5 --mode chat --judge anthropic/claude-opus-4-8
python -m bench run --model openai/gpt-5.2 --mode chat --judge anthropic/claude-opus-4-8
python -m bench run --model openrouter/google/gemini-3-pro --mode chat

# Run an agentic harness (data staged as files in a temp workdir):
python -m bench run --model cli/claude-code --mode agent --judge anthropic/claude-opus-4-8

# Aggregate everything in results/ into a leaderboard:
python -m bench report
```

## The two axes

- **Model axis**: any Anthropic / OpenAI / OpenAI-compatible (OpenRouter → Gemini, Llama, ...) model.
- **Harness axis**: the same tasks run in `chat` mode (data inlined in the prompt — raw model
  reasoning) and `agent` mode (data as files — the harness can write and execute code).
  The chat-vs-agent delta per model is the headline comparison.

## Regenerating the dataset (fresh, uncontaminated instance)

```bash
python -m bench generate --seed 2027   # new data + answer keys for every task
python -m bench validate               # keys re-verified by independent solvers
```

Note: the board-memo rubric and prompts are seed-independent; generators keep the intended
qualitative story (e.g. "EMEA drives the revenue miss") true under any seed.

## Results format

Each run writes `results/<timestamp>_<model>_<mode>.jsonl` — one record per task per trial with
score, per-field correctness, latency, token usage, and the full response text.
`python -m bench report` writes `results/REPORT.md` with a leaderboard and hardest-task table.
